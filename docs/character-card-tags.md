# Canonical Character Card Tags (Draft)

This document defines a **minimal, canonical tag set** for character cards to reduce tag explosion and keep metadata consistent across sources.

## Core tags (draft list ~20)
- adventure
- comedy
- drama
- fantasy
- female
- friendship
- historical
- horror
- isekai
- LGBT
- liminal
- male
- mecha
- mystery
- philosophical
- political
- psychological
- romance
- sci-fi
- slice-of-life
- sports
- supernatural
- thriller
- tragedy
- urban-fantasy
- western
- young-adult

## Notes
- Prefer these canonical tags over ad-hoc variants (e.g., use **sci-fi** instead of “science fiction”).
- Additions must be justified by a clear use-case and reviewed to avoid fragmentation.
